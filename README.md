# Student Performance EDA

## Project Summary

This project performs exploratory data analysis and descriptive statistics on a simulated dataset of 1,200 students. The analysis examines student attendance, study hours, school type, gender, county, and performance in Mathematics, English, and Science.

The analysis includes data structure checks, univariate analysis, bivariate correlations, multivariate comparisons, performance bands, and a trend line between study hours and average score.
